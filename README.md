# Court Scoreboard

Progressive Web App untuk pencatatan skor padel, rally 21 servis, dan badminton.

Aplikasi: https://firmanaf.github.io/Court-Scoreboard/

## Instalasi

Buka alamat aplikasi melalui Chrome atau Safari. Pada Chrome pilih **Install app** dari menu browser. Pada Safari iPhone/iPad pilih **Share > Add to Home Screen**.
